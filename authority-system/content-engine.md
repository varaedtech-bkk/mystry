# Content Engine - PRISM Authority System

## 1) Content Pillars

1. **Functional Thinking for Business Clarity**  
   Show how functional principles reduce ambiguity and improve product communication.

2. **AEO for Technical Brands**  
   Teach how to structure content for AI/search answer retrieval.

3. **Interactive Proof Systems (3D/Demo)**  
   Demonstrate how interactive experiences compress trust-building time.

4. **One-Source Distribution Architecture**  
   Explain publish-once repurposing and channel adaptation.

5. **Authority Case Breakdowns**  
   Analyze wins/losses and map them to PRISM components.

---

## 2) Content Formats

- Long form: article, newsletter, case teardown
- Mid form: carousel, thread, short guide
- Short form: daily POV post, 60-90 sec video, quote card
- Proof form: mini demo, interface walkthrough, before/after comparison

---

## 3) Weekly Publishing Rhythm

- Monday: strategic insight (pillar 1 or 2)
- Tuesday: practical framework (pillar 2 or 4)
- Wednesday: proof/demo (pillar 3)
- Thursday: case or teardown (pillar 5)
- Friday: contrarian POV + CTA

## 5) Repurposing Workflow (Publish Once)

1. Start with one core insight (300-700 words)
2. Extract:
   - one carousel
   - one short video script
   - one thread
   - one email segment
3. Attach one proof element:
   - screenshot
   - clip
   - data point
4. Add channel-native CTA
5. Track response quality and iterate

---

## 6) AEO Quality Checklist

- Does the title map to a real buyer question?
- Does the first paragraph answer directly?
- Are definitions, steps, and examples explicit?
- Is technical terminology explained for decision-makers?
- Is there one clear action at the end?
