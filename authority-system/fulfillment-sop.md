# Fulfillment SOP - PRISM Authority Sprint (21 Days)

This SOP ensures delivery quality and repeatability.

---

## Delivery Promise

By day 21, client receives:
- final positioning system
- AEO-ready authority assets
- one interactive proof asset
- omnichannel distribution workflow
- baseline KPI dashboard and optimization plan

---

## 1) Pre-Kickoff (Day 0)

### Inputs Required
- website and product documentation
- existing content examples
- sales call notes and objections
- access to analytics/search data if available

### Setup Checklist
- create project workspace
- define communication channel
- schedule weekly check-ins (30 min)
- confirm decision-maker availability

---

## 2) Week 1 - Positioning + Retrieval

### Objective
Build a clear strategic core and map high-intent retrieval opportunities.

### Tasks
1. ICP and pain mapping
2. positioning and narrative draft
3. buyer question mining
4. AEO structure map (topics, intents, answer formats)

### Week 1 Deliverables
- Positioning Core document
- Message hierarchy
- Retrieval map (top 10 questions/queries)

### QA Gate
- Is differentiation explicit?
- Can value be explained in under 60 seconds?
- Are mapped queries tied to buying intent?

---

## 3) Week 2 - Asset Production + Proof

### Objective
Produce authority assets that match buyer intent and trust requirements.

### Tasks
1. write first 10 AEO-ready assets
2. structure Q&A blocks for answer retrieval
3. build or script interactive proof (3D/demo walkthrough)
4. align assets with core objections

### Week 2 Deliverables
- 10 authority assets
- Interactive proof storyboard or built experience
- Objection-to-asset mapping sheet

### QA Gate
- Does each asset answer one clear buyer question?
- Does proof directly support key claim?
- Are assets reusable across channels?

---

## 4) Week 3 - Distribution + Momentum

### Objective
Convert assets into a repeatable publishing and optimization workflow.

### Tasks
1. build publish-once repurposing workflow
2. create 30-day calendar with channel adaptation
3. define KPI dashboard and review cadence
4. launch first week of distributed assets

### Week 3 Deliverables
- Distribution engine playbook
- 30-day authority calendar
- KPI scorecard
- Optimization checklist

### QA Gate
- Can the client execute without daily founder dependency?
- Are metrics tied to pipeline, not vanity?
- Is weekly optimization owner assigned?

---

## 5) Communication Cadence

- Kickoff call (60 min)
- Weekly checkpoint (30 min)
- Async updates every 48 hours
- Final handoff call (60 min)

---

## 6) Client Responsibility Matrix

Client must provide:
- final approvals within 24-48 hours
- SME input on technical claims
- access to one decision-maker weekly

Provider (you) must provide:
- clear milestones
- version-controlled assets
- documented decision rationale

---

## 7) Handoff Package (Day 21)

- Final positioning kit
- Published and draft authority assets
- Interactive proof file/link
- Distribution workflows and templates
- KPI baseline and next-30-day recommendations

---

## 8) Post-Sprint Upsell Path

Offer Momentum Retainer:
- monthly new authority assets
- performance tuning
- message testing and refinement
- reporting tied to opportunities and revenue signals
